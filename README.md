# PixelWave Studio — Agency Portfolio Website

A responsive one-page agency portfolio starter built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and WhatsApp enquiry form

## Before publishing
1. Open `script.js`.
2. Replace `91XXXXXXXXXX` with your WhatsApp number, including country code but no plus sign or spaces (example format: `919876543210`).
3. Replace the sample brand name and contact details if you choose a different agency name.
4. Review every claim and only publish details that are true for your business.
5. The work cards are concept projects. Keep the concept/demo disclaimer until they become real commissioned work.

## Preview locally
Open `index.html` in Chrome. For a better local development experience, use VS Code with the Live Server extension.

## Publish on GitHub + Render (static site)
1. Create a GitHub repository and upload these files.
2. In Render, choose **New > Static Site** and connect the repository.
3. Set Build Command to blank and Publish Directory to `.`.
4. Deploy. Render will provide a public URL.

## Important
This starter does not include a backend, database, analytics or real form submission. The contact form opens WhatsApp with a prefilled message after you add your number.


## Gallery images
The three concept gallery cards now use remotely hosted Unsplash photographs. An internet connection is required for those photos to load. The concepts are illustrative and must not be presented as commissioned client projects.
